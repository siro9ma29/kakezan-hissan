# マス・モンスターズ（かけ算のひっ算）

小学3年生向け。2けた×1けたのかけ算のひっ算をステップごとに解いて、モンスターにこうげきするRPG風練習アプリ。

- 公開URL: https://siro9ma29.github.io/kakezan-hissan/
- index.html 1ファイルで動作（外部ライブラリ・Webフォントなし。フォントは端末に入っているものを使う）

# 【マス・モンスターズ】引き継ぎメモ（2026-11-20）
- 対象・単元：3年 かけ算のひっ算（2けた×1けた）
- できていること：タブレットの横画面（幅820px以上）と縦画面（幅600px以上）で、スクロールせずに1画面ですべて見られる。Googleフォントの読みこみをやめ、ネットなしで同じ見た目になる
- 決めた仕様（理由も一言）：
  - 横画面は 左＝バトル／中＝ひっ算（けいさんメモは ひっ算の下）／右＝テンキーと「こうげき！」の3列（縦に積むと高さが足りないため）
  - マス・キー・モンスターの大きさは画面の高さに合わせて変わる（端末ごとの高さのちがいに合わせるため）
  - ステージえらびも横画面では2列にして1画面に入れる
  - 縦画面のタブレットでは、バトルの空き（モンスターのまわり）をちぢめて高さを合わせる（ひっ算とキーの大きさを守るため）
  - スマホの縦画面は変えていない（高さが足りず、1画面に入れると小さくなりすぎるため）
  - フォントは端末のもの（丸ゴシック系／ドット風の代わりに等幅ゴシック）。外部に頼らないルールのため
- 未解決・次にやること：学校の端末の縦・横画面で実際に見え方を確かめる
- ファイル名／GitHubの場所：siro9ma29/kakezan-hissan の index.html
